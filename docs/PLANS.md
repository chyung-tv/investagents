# Plans

Plans are repo files. Chat is not the system of record.

- Small change: skip a plan; still run `verify`.
- Behavioral or multi-file work: add `docs/exec-plans/active/<slug>.md` before coding. Log decisions as they happen. Move to `docs/exec-plans/completed/` when done.
- Recurring debt: [tech-debt.md](exec-plans/tech-debt.md)

Template:

```markdown
# <title>

Status: active
Started:

## Intent

## Progress

## Decisions
```
